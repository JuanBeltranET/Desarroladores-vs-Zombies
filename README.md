# Desarroladores-vs-Zombies:
Trabajo de Base de Datos y Algoritmos y Estructura de Datos sobre el proyecto interdisciplinario

# Nuestro Proyecto:

# 1. 🎯 TEMÁTICA DEL PROYECTO
Desarrollo de un videojuego 2D funcional con persistencia de datos relacional, análisis de métricas en tiempo real e implementación de estructuras de datos eficientes.

El proyecto integra los contenidos nodales de ambas asignaturas:

Base de Datos: Diseño lógico, normalización (1FN→3FN), lenguaje SQL para consulta y manipulación, integridad de datos, y generación de reportes analíticos.
Algoritmos y Estructuras de Datos: Razonamiento algorítmico, estructuras estáticas y dinámicas (arrays, pilas, colas, listas), recursividad, manejo de archivos y análisis básico de complejidad.
El resultado es un sistema demostrable que simula un entorno profesional de desarrollo: trabajo colaborativo, gestión ágil, control de versiones y documentación técnica.

# 2. 📖 INTRODUCCIÓN
En el contexto actual del desarrollo de software, los sistemas interactivos generan grandes volúmenes de información estructurada que requieren ser almacenados, consultados y analizados con precisión. Este proyecto interdisciplinario busca que los estudiantes apliquen los conocimientos adquiridos en Base de Datos y Algoritmos y Estructuras de Datos en un escenario realista: el desarrollo de un videojuego jugable.
